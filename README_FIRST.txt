ARES: FIRST COLONY | OFFLINE AND GITHUB PAGES EDITION

TO PLAY WITHOUT INTERNET:
Extract this ZIP first. Double-click index.html in Chrome or Edge.
All required scripts, images, audio and movies are included.
Do not open the index.html while it is still inside the ZIP.

FOR GITHUB PAGES:
Upload the CONTENTS of this folder to a public GitHub repository.
Settings -> Pages -> Deploy from a branch -> main / (root) -> Save.
Then use https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

IMPORTANT:
- The GitHub Pages URL requires internet initially.
- This offline package does not call NASA live data.
- The included cinematic videos may be large, so first download can take time.
- If browser security settings block file playback, serve this folder over localhost using any local static server.
